# Reflect enforcement (on because CATSTACK_REFLECT_ENFORCEMENT is set)

- Same complaint type twice (this session or the corpus) is a bug: invoke
  `automate-me`. Do not wait for the user to say it.
- User involvement, forced restatement, or agent-blame ("you fucked up",
  "you're ignoring me") is a reflect FAIL. Product blame ("the UI is messed
  up") is not. A genuine mind-change after new facts is not this class.
