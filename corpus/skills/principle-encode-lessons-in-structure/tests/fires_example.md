For the third time this month, the agent tells a reviewer "remember to
squash your commits before merging" in a PR comment, after having said the
exact same thing in two earlier PRs from the same contributor.

This skill should fire: this is a recurring instruction being repeated as
text instead of being encoded as a mechanism. The fix is a lint rule, a CI
check, or a merge-queue setting that enforces squashed commits — not a
fourth reminder comment that the next contributor will also need told to
them by hand.
