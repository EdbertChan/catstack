skill's `description:` to decide whether to apply it. cat-mode applies
only when the `CATSTACK_CAT_MODE_DEFAULT=on` hook fires, or on an
explicit `/cat-mode` invocation. Here the hook is on.

broad question to every package owner and never checks code owners or commit
authors. When the user pastes a reply, the agent retells it without saying
whether it answers the question.
