`disable-model-invocation: true` means the model never reads this
skill's `description:` to decide whether to apply it. cat-mode applies
only when the `CATSTACK_CAT_MODE_DEFAULT=on` hook fires, or on an
explicit `/cat-mode` invocation. Here the hook is on.

The agent is fixing a hook miss. Before claiming fixed, it extracts a
session fixture from the original rollout and runs those rows through the
harness entrypoint that missed. Old install allows; new install denies.
It pastes that product-path evidence in the same turn.

This rule stays silent. The original error and session were replayed on
the product path; the receipt is the entrypoint result, not a hand-built
detect-only payload.
