# Creating PRs (apply everywhere)

When asked to make, open, create, publish, or update a PR, read the
`draft-pr` skill first (`skills/draft-pr/SKILL.md` or the installed
`draft-pr` skill). If the current repo has `skills/make-pr/SKILL.md`, use
that overlay. Do not draft title or body from the latest commit message, and
do not use a generic `gh pr create` Summary / Test plan template.

Slash commands `/pr-skill`, `/draft-pr`, and `/make-pr` all enter this skill.
