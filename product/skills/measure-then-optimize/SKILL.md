# Measure then optimize

Follow [Measure, identify, fix, verify](playbooks/measure-identify-fix-verify.md)
before making a performance change. A performance fix is done only when the
user's symptom was measured before and after under the same real conditions by
a committed, rerunnable program, and the ledger's `judge` verdict is `pass`.
